How to run the project.
1.	Set up virtual environment.
2.	Install all dependencies from requirements.txt or pyproject.toml.
3.  Run the backend using "python backend.py" or "uvicorn backend:app --reload --host 127.0.0.1 --port 9999"
3.	Run the frontend using - "streamlit run frontend.py" at # http://localhost:8501
